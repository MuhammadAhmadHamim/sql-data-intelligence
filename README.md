# 📊 SQL Data Intelligence: Relational Design & Analytics Portfolio

A curated collection of my database engineering work, ranging from complex query optimization to professional schema design. This repository serves as a technical portfolio for **Database Management Systems (DBMS)** and **Business Intelligence** projects.

---

## 🎯 Portfolio Objectives
* **Data Modeling:** Designing 3rd Normal Form (3NF) schemas to ensure data integrity.
* **Complex Analytics:** Utilizing CTEs, Window Functions, and Subqueries to solve real-world business problems.
* **Performance:** Writing optimized SQL for large-scale datasets.
